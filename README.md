# Secure App – DevSecOps Demo

## Pipeline Features
- SAST (Semgrep)
- Dependency scan (pip-audit)
- Unit tests (pytest)
- SBOM generation (CycloneDX)
- Container scan (Trivy)
- Build promotion (trusted build)

- `sbom.json`
- `trivy-report.json`
- `dependency-scan.json`
- `test-results.xml`
- `trusted.env`
